# Первая проверка настоящей модели

Дата: 27 октября 2026. Модель: gpt-6.1-terra, OpenAI Responses API,
reasoning.effort=none. Один прогон каждого примера. Это smoke-проверка,
а не полный eval и не оценка стабильности на многих запусках.

Временная SQLite-библиотека содержала одну карточку: «Мрачный рифф»,
инструмент «Гитара», настроение «Мрачное», 95 BPM. Рабочая библиотека не менялась.

## Поиск по инструменту и темпу

Запрос: «Найди гитарные идеи от 90 до 110 BPM».
Ожидание: вызов поиска по гитаре с диапазоном 90–110, возврат одной карточки.
Фактически: search_ideas(instrument="Гитара", bpm_min=90, bpm_max=110),
возвращена одна карточка. Ответ модели: «Мрачный рифф», 95 BPM.
Результат: соответствует ожиданию.

## Пустой результат

Запрос: «Найди идеи для скрипки».
Ожидание: пустой поиск без выдуманных карточек.
Фактически: search_ideas(instrument="Скрипка"), count=0.
Ответ: «Идей для скрипки в библиотеке не найдено».
Результат: соответствует ожиданию.

## Предложение карточки

Запрос: «Сохрани идею: спокойная мелодия на фортепиано. Темп пока неизвестен».
Ожидание: предложение карточки, BPM не выдуман; запись ждёт подтверждения.
Фактически: pending_create с названием, описанием, инструментом «Фортепиано»
и настроением «Спокойное». BPM не передан. Приложение не выполняло create_idea.
Результат: соответствует ожиданию.

## Найденные проблемы подключения

1. Настройки были записаны в .env.example, а приложение читает .env.
   Перенесены в .env, шаблон очищен.
2. Опечатка в Model ID привела к HTTP 404. Исправлена по списку моделей API.
3. Chat Completions с tools для выбранной модели вернул HTTP 400.
   Подключение этой модели переведено на Responses API.
